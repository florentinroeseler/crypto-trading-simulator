# SvelteKit Projekt

## Quick-Installation

Das Projekt lässt sich einfach mit Docker Compose starten:

```bash
docker-compose up
```

**Hinweis:** Der erste Start des Projekts kann einige Minuten dauern, da alle Abhängigkeiten installiert und gebündelt werden müssen. Die Anwendung kann anfänglich langsam reagieren, wird aber nach wenigen Minuten deutlich flüssiger laufen, sobald alle Ressourcen vollständig geladen sind.

## Hinweis zur Ordnerstruktur

Die Ordnerstruktur dieses Projekts wird in weiten Teilen durch das SvelteKit-Framework vorgegeben. Dies ist ein standardisiertes Layout, das den Best Practices für SvelteKit-Anwendungen entspricht. **Ich hoffe, Sie können das bei der Bewertung berücksichtigen**
